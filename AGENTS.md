# Antigravity Agent Guidelines for Agnes

- **Auto-execution & Zero Friction**: 
  - The user prefers all modifications to be applied automatically without prompting for confirmation or manual approval.
  - Do NOT use interactive modal questions (`ask_question`) unless the user explicitly asks to be interviewed. Always pick the optimal implementation and apply it directly.
  - Proactively edit files, build, and deploy. Do not ask for permission to run build or git commands.
  - Keep responses concise, direct, and actionable.
